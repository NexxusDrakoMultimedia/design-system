# Icon

The brand's own line icon set: 27 icons on a 24px grid, 2px round strokes, drawn in the current text colour.

- **Consumer provides:** `name` (see the Icons asset group: play, music, book, gamepad, steering-wheel, flag, mic, radio, pen, code, calendar, clock, users, heart, star, link, external, mail, download, search, menu, close, arrow-right, check, info, warning, error), optional `size` (px, default 24) and `label`.
- Pass `label` when the icon stands alone and means something ("Open menu"); leave it off when a word sits beside it, so screen readers skip it.
- Colour comes from the parent's `color`: use `accent`, `ink` or a status token. Icons must hold 3:1 against their ground.
- Never use emoji in place of these icons. Don't add platform logos (Twitch, YouTube, Discord) to this set; use each platform's official mark from its press kit.
