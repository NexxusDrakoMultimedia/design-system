# LowerThird

A stream and video overlay: the name on a maroon bar in the display face, a subtitle on a gold bar, and an optional avatar.

- **Consumer provides:** `name`, optional `subtitle` and `avatar` (image URL).
- Uses only `maroon` and `gold`, so it looks the same in every theme and over any footage.
- Place it bottom-left with at least `space-10` from the frame edges. Keep the subtitle to a few words.
