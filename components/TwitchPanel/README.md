# TwitchPanel

A 320px info panel for the Twitch "About" section: maroon header with a gold display title, body text below.

- **Consumer provides:** `title` (one or two words: Schedule, Rules, Discord, Music) and body content as children.
- Render it and capture at 320px wide to make the panel image, or use it on the website for the same blocks.
- Give times with the timezone (AEST). Keep each panel to a few short lines.
