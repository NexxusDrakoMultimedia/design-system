# StreamScreen

A full 1920×1080 OBS scene: maroon ground, gold rings bleeding off the right edge (the avatar-ring motif), avatar, a big gold title and a white subtitle.

- **Consumer provides:** `variant` (`starting` · `brb` · `ending` · `offline`), optional `avatar` (image URL), `title`, `subtitle` and `detail` (one short uppercase line, such as the stream topic and time).
- Each variant has default copy in Nexxus's voice; override it per stream.
- Add it as a browser source at 1920×1080 in OBS. It is theme-independent (maroon, gold, white only).
- Keep the subtitle to one sentence; give times in AEST.
