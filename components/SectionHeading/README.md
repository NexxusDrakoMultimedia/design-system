# SectionHeading

A section title in the display face (HK Modular, Orbitron fallback), uppercase, in `accent`, with an optional eyebrow line.

- **Consumer provides:** the title as children, optional `eyebrow`, and `level` (heading level, default 2).
- Keep titles to one to three words. The eyebrow is `ink-muted` small caps text giving context ("What I make", "Season 2").
- One SectionHeading per page section; don't stack two.
