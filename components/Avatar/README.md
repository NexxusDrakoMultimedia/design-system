# Avatar

The avatar ring image, shown round at 32, 48 or 96px.

- **Consumer provides:** `src` (the `avatar-ring.png` asset, or another ringed portrait), optional `alt` (defaults to "Nexxus Drako") and `size` (`sm` · `md` · `lg`).
- Use the brand's own ringed artwork. Don't add a second ring or border, because the gold ring is already in the image.
- Pass `alt=""` when a name sits right next to it.
