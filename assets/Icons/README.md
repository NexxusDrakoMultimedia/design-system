The brand line icon set: 27 icons, 24×24 grid, 2px stroke, round caps and joins, no fills.

- The SVG files are single-ink maroon (#7f0000) for use on white or light grounds. For gold, white or any other colour, use the `Icon` component (it draws in `currentColor`) or change the `stroke` value in a copy of the file.
- Hold icons at 3:1 or better against their ground; never pair them with emoji.
- New icons follow the same grid and stroke. Platform logos (Twitch, YouTube, Discord, Bluesky) are not part of this set: use each platform's official mark.
